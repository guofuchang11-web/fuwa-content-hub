## 快速入门

### 首次使用

1. **打开应用**
   - 浏览器访问应用地址
   - 或直接打开 `index.html` 文件

2. **创建者初始化**
   - 首次使用会弹出创建者设置窗口
   - 输入创建者名称
   - 设置授权密码（用于数据清零等敏感操作）
   - 点击"确认设置"

3. **开始使用**
   - 左侧导航栏选择功能板块
   - 顶部显示当前板块名称
   - 所有数据自动保存在本地

### 数据存储说明

- **前端模式**：数据存储在浏览器IndexedDB中
- **后端模式**：数据存储在服务器数据库中
- **数据备份**：建议定期导出数据备份

## 内容生产板块

### 1. 选题管理

**功能说明**：管理内容选题，支持创建、编辑、删除、搜索。

**操作步骤**：
1. 点击"新建选题"按钮
2. 填写选题标题、描述、分类、标签
3. 设置优先级（高/中/低）
4. 选择状态（草稿/进行中/已完成）
5. 点击保存

**字段说明**：
- 标题：选题名称（必填）
- 描述：选题详细说明
- 分类：选题所属类别
- 标签：关键词标签（多个用逗号分隔）
- 优先级：高/中/低
- 状态：草稿/进行中/已完成

### 2. 脚本创作

**功能说明**：创作视频脚本，支持多种脚本类型。

**脚本类型**：
- 口播脚本
- 分镜脚本
- 剧情脚本
- 带货脚本
- 教育类脚本

**操作步骤**：
1. 点击"新建脚本"
2. 选择关联选题（可选）
3. 选择脚本类型
4. 填写脚本标题和内容
5. 设置预计时长
6. 保存脚本

### 3. 对标拆解脚本

**功能说明**：拆解对标账号的优秀脚本，学习其结构和话术。

**操作步骤**：
1. 输入对标视频链接或粘贴脚本内容
2. 点击"开始拆解"
3. 系统自动分析脚本结构
4. 查看拆解结果：
   - 开头钩子分析
   - 内容结构拆解
   - 话术技巧总结
   - 可复用模板提取

### 4. 对标视频拆解

**功能说明**：深度拆解对标视频，分析其成功要素。

**拆解维度**：
- 视频基本信息（时长、发布时间、数据）
- 开头3秒钩子分析
- 内容结构拆解
- 画面节奏分析
- 文案话术分析
- 背景音乐分析
- 互动引导分析
- 爆款要素总结

### 5. 对标视频库

**功能说明**：收藏和管理对标视频，方便随时查看和学习。

**操作步骤**：
1. 点击"添加对标视频"
2. 输入视频链接
3. 填写视频标题和账号名称
4. 添加标签和备注
5. 保存到视频库

### 6. 拍摄素材

**功能说明**：管理拍摄素材，支持上传、分类、搜索。

**支持格式**：
- 图片：JPG、PNG、GIF、WebP、SVG
- 视频：MP4、MOV、AVI、MKV
- 音频：MP3、WAV、FLAC
- 文档：PDF、DOC、DOCX、TXT

**操作步骤**：
1. 点击"上传素材"或拖拽文件到上传区域
2. 支持批量上传
3. 填写素材名称、分类、标签
4. 保存素材

### 7. 成片库

**功能说明**：管理已完成的视频成片。

**操作步骤**：
1. 上传成片视频
2. 填写视频信息（标题、描述、标签）
3. 关联选题和脚本
4. 记录发布状态

### 8. 成片视频拆解分析

**功能说明**：对已发布的成片进行数据复盘和内容分析。

**分析维度**：
- 播放数据（播放量、完播率、平均观看时长）
- 互动数据（点赞、评论、转发、收藏）
- 内容分析（开头钩子、内容结构、话术效果）
- 优化建议（基于数据给出改进方向）

## AI创作板块

### 1. AI视频生成

**功能说明**：使用AI生成视频，支持文本生成视频和图片生成视频。

**操作步骤**：
1. 输入视频描述或上传参考图片
2. 选择视频风格（写实/动漫/电影感等）
3. 设置视频时长（5秒/10秒/15秒）
4. 选择画面比例（16:9/9:16/1:1）
5. 点击"生成视频"
6. 等待生成完成
7. 预览并下载视频

### 2. AI视频提示词专业版

**功能说明**：专业级AI视频提示词生成工具，基于即梦2.5九维控场。

**九大控场维度**：
1. 主体描述
2. 场景环境
3. 镜头语言
4. 光线氛围
5. 色彩风格
6. 运动轨迹
7. 时间节奏
8. 特效风格
9. 画质参数

**五大公式**：
- 公式一：主体+场景+镜头+光线
- 公式二：动作+轨迹+节奏+特效
- 公式三：风格+色彩+氛围+画质
- 公式四：人物+表情+服装+道具
- 公式五：产品+卖点+场景+光影

**操作步骤**：
1. 选择提示词公式
2. 填写九个维度的参数
3. 实时预览生成的提示词
4. 一键复制提示词
5. 到AI视频生成工具中使用

### 3. 即梦提示词工坊

**功能说明**：即梦2.5专用提示词工坊，包含官方案例库。

**特色功能**：
- 五大公式切换
- 九维控场输入
- 11种转场技巧插入
- 提示词实时生成
- 7个官方案例库（丹顶鹤起舞、人物写真、产品广告、剧情短片、美食制作、套娃延长、精准编辑）

### 4. 人物九视图

**功能说明**：生成角色九视图设定，确保AI生成视频中人物一致性。

**九大模块**：
1. 人物三视图（正面/侧面/背面）
2. 身材三视图（体态展示）
3. 面部细节（眼部/唇部/皮肤/发丝）
4. 情绪细节（多种表情）
5. 习惯动作
6. 饰品展示
7. 常穿服装
8. 服装材质
9. 鞋履展示

**操作步骤**：
1. 填写角色基本信息（年龄/性别/职业/发型）
2. 填写九大模块的详细描述
3. 点击"生成九视图提示词"
4. 复制提示词到AI绘图工具
5. 生成3×3网格的九视图

### 5. AI-Vlog编导

**功能说明**：AI辅助Vlog创作，从选题到成片全流程指导。

**六种Vlog类型**：
1. 日常记录型
2. 旅行攻略型
3. 美食探店型
4. 知识分享型
5. 产品测评型
6. 剧情演绎型

**操作步骤**：
1. 选择Vlog类型
2. 输入Vlog主题
3. 系统自动生成分镜脚本
4. 查看编导思维指南
5. 根据脚本拍摄和剪辑

## 直播运营板块

### 1. 主播管理中心

**功能说明**：管理主播信息、排班、GMV排行榜。

#### 主播排班表

**功能说明**：创建和管理主播排班，支持选择填空和输入创建。

**操作步骤**：
1. 选择日期（2026年9月日历）
2. 选择主播（下拉选择或输入新主播）
3. 选择直播平台（抖音/小红书/视频号/快手）
4. 填写直播账号
5. 设置开播时间和结束时间
6. 填写备注
7. 保存排班

#### 主播GMV排行榜

**功能说明**：展示主播GMV排名，支持按UV值考量。

**排序维度**：
- GMV金额（主要）
- UV价值（参考）
- 订单数
- 客单价

**时间维度**：
- 每日
- 每周
- 每月

**展示样式**：
- Top10主播列表
- 前三名金/银/铜徽章
- GMV进度条（相对最大值）
- 具体GMV金额（元，小数点后两位）

#### 上传直播大屏数据

**功能说明**：上传直播数据大屏截图，自动识别关键数据。

**操作步骤**：
1. 点击上传区域或粘贴图片
2. 选择主播（下拉选择或输入）
3. 选择直播账号
4. 选择直播平台
5. 填写备注
6. 系统自动识别数据：
   - 总GMV
   - 总订单数
   - 客单价
   - 峰值在线
   - 平均观看时长
   - 转化率
   - 互动率
   - 曝光进房率
7. 确认识别结果（可编辑）
8. 保存数据

### 2. 直播复盘

**功能说明**：直播结束后进行数据复盘和AI智能诊断。

**操作步骤**：
1. 上传直播数据大屏截图
2. 选择直播账号和平台
3. 系统自动识别数据
4. 点击"生成复盘报告"
5. 系统基于数据生成11维度诊断报告：
   - 整体结论
   - 核心数据总览
   - 流量曲线分型诊断
   - 成交密度&直播节奏诊断
   - 分时段精细化诊断&优化方案
   - 货品结构诊断
   - 流量来源&投流策略诊断
   - 人群精准度诊断
   - 下一场直播优先级行动清单
   - 下一场关键监测节点
   - 本场最终总结&底层优化逻辑
6. 查看复盘报告（Tab切换）
7. 导出报告

### 3. 直播排班日历

**功能说明**：以日历视图展示直播排班，基于2026年9月中国日历。

**日历特点**：
- 2026年9月完整月历
- 星期和日期与真实日历一致
- 显示排班信息
- 点击日期查看详情

## 数据大屏

### 业务中控大屏

**功能说明**：汇总所有业务板块数据，实时展示核心指标。

**时间维度切换**：
- 每日
- 每周
- 每月
- 90天

### 总览卡片（5个）

#### 1. 总GMV
- 中心圆形仪表盘
- 4指标环绕：抖音/视频号/小红书/快手
- 显示总GMV金额（元，小数点后两位）

#### 2. 总消耗（千川）
- 中心圆形仪表盘
- 4指标环绕：抖音/视频号/小红书/快手
- 显示总消耗金额

#### 3. 内容生产
- 中心圆形仪表盘
- 5指标环绕：
  - 拍摄素材总条数
  - AI视频生成总条数
  - 剪辑总条数
  - 发布总条数
  - 发布平台条数（抖音/视频号/快手/小红书）

#### 4. 主播排行榜
- Top10主播条形统计图
- 按GMV降序排列
- 主参考UV值排序
- 前三名金/银/铜排名徽章
- 每个主播带GMV进度条
- 显示具体GMV金额

#### 5. 视频总曝光
- 中心圆形仪表盘
- 4指标环绕：抖音/视频号/小红书/快手
- 显示总曝光量（千分位格式）

### 排行榜（3个）

#### 主播GMV排行榜
- Top10主播，按GMV降序排列
- 主参考UV值排序
- 前三名：金色🥇/银色🥈/铜色🥉排名徽章
- 每个主播带GMV进度条（相对最大值）
- 显示具体GMV金额（元，小数点后两位）

#### 引流视频排行榜
- Top10引流视频，按消耗降序排列
- 前三名金色渐变排名徽章
- 显示视频名称和消耗金额
- Hover青色高亮效果

#### 视频曝光排行榜
- Top10视频，按曝光量降序排列
- 前三名绿青渐变排名徽章
- 显示视频名称和曝光量（千分位格式）
- Hover绿色高亮效果

### 数据自动汇总机制

**汇总数据源**：
- 直播复盘 → 总GMV、主播GMV、直播数据
- 投放端 → 千川消耗、平台细分、引流视频、曝光视频
- 账号数据 → 播放/点赞/评论
- 拍摄素材 → 素材条数
- AI生成 → 生成条数
- 成片 → 剪辑条数
- 发布 → 发布条数

**自动刷新**：
- 进入数据大屏时自动汇总一次
- 每30秒自动刷新汇总
- 切换时间维度（日/周/月）时立即重新汇总
- 所有数据按数值大小降序排列

## 系统设置

### 1. 创建者授权管理

**功能说明**：管理创建者权限，只有创建者可以执行一键清零等敏感操作。

**设置创建者**：
1. 首次使用时弹出创建者设置窗口
2. 输入创建者名称
3. 设置授权密码（至少6位）
4. 确认密码
5. 点击"确认设置"

**修改创建者密码**：
1. 进入系统设置
2. 点击"创建者授权管理"
3. 输入原密码验证
4. 设置新密码
5. 保存

### 2. 一键清零所有数据

**功能说明**：清空系统中所有数据，仅创建者可执行。

**操作步骤**：
1. 进入系统设置
2. 点击"一键清零所有数据"
3. 弹出确认窗口
4. 输入创建者密码验证
5. 点击"确认清零"
6. 等待清零完成

> ⚠️ 此操作不可恢复，请先备份数据！

### 3. 数据管理

**导出数据**：
1. 进入系统设置 → 数据管理
2. 点击"导出数据"
3. 选择导出范围（全部/指定板块）
4. 下载JSON格式备份文件

**导入数据**：
1. 进入系统设置 → 数据管理
2. 点击"导入数据"
3. 选择之前导出的JSON文件
4. 确认导入
5. 等待导入完成

### 4. 系统配置

**配置项**：
- 系统名称
- 运行内存显示（8880TB）
- 存储容量显示（8880TB）
- 单文件大小限制
- 支持格式列表
- 后端API地址（前后端对接时配置）

### 5. 技能中心

**功能说明**：查看系统集成的所有专业Skill。

**Skill分类**：
- 内容生产类
- 视频剪辑类
- AI创作类
- 数据分析类
- 逆向工程类
- 安全测试类
- 其他工具类

**操作**：
- 按分类浏览Skill
- 搜索Skill
- 查看Skill详情
- 跳转到对应功能板块

### 6. 行业对标中心

**功能说明**：查看全网内容中台系统排行榜和功能对比。

**功能**：
- TOP20内容中台系统排行榜
- 功能对比矩阵
- 优秀功能借鉴清单
- 行业趋势分析

## 常见问题

### Q: 数据存储在哪里？会丢失吗？

A: 纯前端模式下，数据存储在浏览器的IndexedDB中。清除浏览器数据或更换浏览器会导致数据丢失。建议定期使用"导出数据"功能备份。部署后端服务后，数据存储在服务器数据库中，更加安全可靠。

### Q: 支持哪些文件格式上传？

A: 支持37+种格式，包括：
- 文档：PDF、DOC、DOCX、TXT、MD、PPT、PPTX、XLS、XLSX、CSV
- 图片：JPG、JPEG、PNG、GIF、WebP、SVG、BMP、TIFF
- 视频：MP4、MOV、AVI、MKV、FLV、WMV、WebM
- 音频：MP3、WAV、FLAC、AAC、OGG
- 压缩包：ZIP、RAR、7Z、TAR、GZ

### Q: 如何修改创建者密码？

A: 进入系统设置 → 创建者授权管理 → 输入原密码验证 → 设置新密码 → 保存。如果忘记原密码，需要清除浏览器数据后重新初始化（会丢失所有数据）。

### Q: 数据大屏数据不更新怎么办？

A: 数据大屏每30秒自动刷新一次。如果数据没有更新，请检查：
1. 是否在对应板块录入了数据
2. 时间维度选择是否正确
3. 尝试手动刷新页面
4. 检查浏览器控制台是否有报错

### Q: 如何对接后端API？

A: 1. 部署后端服务（参考部署指南）
2. 进入系统设置 → 系统配置
3. 填写后端API地址（如 http://localhost:8000）
4. 保存配置
5. 系统会自动使用后端API存储和读取数据

### Q: 手机端和电脑端界面不一样吗？

A: 系统采用响应式设计，会根据设备屏幕尺寸自动调整布局。手机端和电脑端功能完全一致，只是界面布局会根据屏幕大小自适应调整。

### Q: 如何备份数据？

A: 有两种方式：
1. 前端数据备份：系统设置 → 数据管理 → 导出数据（JSON格式）
2. 后端数据备份：运行 scripts/backup.sh 脚本，自动备份数据库和上传文件

### Q: 直播复盘报告如何生成？

A: 1. 进入直播复盘板块
2. 上传直播数据大屏截图
3. 选择直播账号和平台
4. 系统自动识别数据
5. 点击"生成复盘报告"
6. 系统基于数据和行业基准生成11维度诊断报告
7. 可以切换Tab查看不同维度的分析
8. 可以导出报告

### Q: 主播GMV排行榜如何排序？

A: 主播GMV排行榜主要按GMV金额降序排列，同时参考UV价值。前三名会显示金/银/铜徽章。可以切换每日/每周/每月时间维度查看不同周期的排名。

### Q: 投放端数据如何录入？

A: 1. 进入投放端板块
2. 上传投放消耗大屏截图
3. 选择投放平台（抖音/小红书/视频号/快手）
4. 选择直播账号
5. 选择主播名字（下拉选择或输入新主播）
6. 系统自动识别数据（总消耗、总曝光、总点击、转化率、ROI等）
7. 确认识别结果（可手动编辑修正）
8. 保存数据
